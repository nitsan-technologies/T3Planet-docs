Decide which backend user groups may see or change AI Search.

1. Go to **AI Universe → AI Foundation → AI Permissions**.
2. Under **TYPO3 Backend Usergroups**, choose a group (or click **Add Backend Usergroup**).
3. In the **Permission Matrix**, find the **AI Chatbot/Search** entries:
   - **Search Widget Settings** – the search settings
   - **Predefined Questions** – the example questions
   - **Search Query History** – what visitors searched
4. Set the access and save.

![AI Permissions with the tabs Groups & Permissions and Permission Matrix](../images/ai-permissions.webp)

<Note>
Administrators always have full access.
</Note>
