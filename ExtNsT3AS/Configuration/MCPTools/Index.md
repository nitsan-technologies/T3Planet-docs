<a id="mcp-tools"></a>

**AI provider:** AI Search uses the AI provider you set up in AI Foundation. See [AI Providers](/en/latest/ExtNsT3AF/Configuration/AIProviders/Index).

**MCP tools:** MCP lets an AI assistant (for example in a code editor) read and change AI Search settings and data sources for you. You only need this if your team works with such assistants. See [MCP Server](/en/latest/ExtNsT3AF/Integrations/MCPServer/Index) and [MCP Tools](/en/latest/ExtNsT3AF/Integrations/MCPTools/Index).
