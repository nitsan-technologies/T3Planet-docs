<a id="ask-ai-agent-tab-overview"></a>

**Path:** **AI Foundation > AI Agent > Overview**

**What it shows:** the current state of the AI agent for your account.

- **Counters** — **Registered tools**, **Executable now**, **Locked**, and **Contributing extensions**. A tool is *locked* when it has no declared severity or when its extension is not entitled to run.
- **Keyboard shortcut** — choose how the AI agent opens in this browser.
- **Availability** — whether the AI agent window is enabled for you, where the shortcut is stored (per browser), and that unsolicited suggestions are off by product policy.
- **How tools register** and **Tools by owning extension** — every extension that registers tools, with total, executable, and locked counts.

**What you do here:**

1. Check that **Executable now** is greater than 0. If it is 0, see [Troubleshooting](/en/latest/ExtNsT3AF/AskAiAgent/Troubleshooting/Index).
2. Under **Keyboard shortcut**, select **Ctrl/Cmd+Shift+K (recommended)** or **Ctrl/Cmd+K (opt-in)**.
3. Reopen the AI agent, or reload other backend tabs, to apply the shortcut.

<Note>
The shortcut is stored in the browser, not in the backend user record. Each editor sets it on each browser they use.
</Note>
