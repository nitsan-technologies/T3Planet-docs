<a id="ask-ai-agent-tab-demand"></a>

**Path:** **AI Foundation > AI Agent > Demand signals**

**What it shows:** how often editors tried to use a tool that is locked for them, per extension and tool, with the time of the last attempt.

- The counts stay on this installation. Sharing with T3Planet is disabled and cannot be enabled in this release.

**What you do here:** review the list to see which locked tools editors need. Unlock a tool by adjusting the group's **Blocked tools** or **Read-only agent** setting, or by installing and entitling the extension that provides it.
