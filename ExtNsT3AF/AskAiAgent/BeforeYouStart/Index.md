<a id="ask-ai-agent-before"></a>

Make sure that the following requirements are met:

1. **An AI provider with tool calling is configured.** Add it in **AI Foundation > AI Providers** and click **Test connection**. See [AI Providers](/en/latest/ExtNsT3AF/Configuration/AIProviders/Index).
2. **You have access to the AI agent.** Administrators always have access. Editors need **AI Agent access** in their backend user group (see [Where the AI agent opens](/en/latest/ExtNsT3AF/AskAiAgent/WhereOpens/Index)).
3. **You have normal TYPO3 permissions** for the pages and records you want to work with.

<Note>
This guide describes the tools that ship with AI Foundation. Extensions that build on AI Foundation can add further tools; they are documented in their own manuals.
</Note>
