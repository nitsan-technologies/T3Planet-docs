<a id="ask-ai-agent-shortcuts"></a>

| Shortcut | Action |
|---|---|
| <kbd>Ctrl/Cmd+Shift+K</kbd> | Open the AI agent. This is the default and recommended shortcut. |
| <kbd>Ctrl/Cmd+K</kbd> | Open the AI agent (opt-in). Replaces the TYPO3 Live Search shortcut. |
| <kbd>Enter</kbd> | Send the message. |
| <kbd>Esc</kbd> | Close the AI agent window. |

To change the shortcut:

1. Open **AI Foundation > AI Agent > Overview**.
2. Go to the **Keyboard shortcut** card.
3. Select **Ctrl/Cmd+Shift+K (recommended)** or **Ctrl/Cmd+K (opt-in)**.
4. Reload other open backend tabs.

The setting is stored per browser.

<Warning>
<kbd>Ctrl/Cmd+K</kbd> is the shortcut of TYPO3 **Live Search**. If you select it for the AI agent, Live Search no longer opens with the keyboard; it remains available through the search icon in the top bar. Keep the default <kbd>Ctrl/Cmd+Shift+K</kbd> unless your editors agree on the change.
</Warning>
