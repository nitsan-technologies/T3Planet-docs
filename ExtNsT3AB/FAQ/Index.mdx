Short answers to common questions about AI Builder (T3AB).

### What can T3AB build?

TYPO3 content blocks, forms and complete extensions, from a description in plain language.

### How does it work?

In three steps. **Start:** describe what you need, for example the extension name, vendor and function. **Refine:** T3AB asks follow-up questions to understand the goal. **Launch:** the code is generated, and you preview and download it in the browser. See [How T3AB Works](/en/latest/ExtNsT3AB/HowT3ABWorks/Index).

### Is T3AB free?

No. T3AB is a premium extension with no free version. Test it with the 30-day free trial, then buy a license.

### Which TYPO3 extensions does T3AB need?

The TYPO3 Form extension (`EXT:form`), Content Blocks (`EXT:content_blocks`) and the T3Planet Shop module (`EXT:ns_license`).

### Something is not working

Open a ticket at [t3planet.de/support](https://t3planet.de/support) with your TYPO3, PHP and T3AB versions and the exact error text.
