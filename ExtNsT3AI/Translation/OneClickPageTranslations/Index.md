Translates a page from the default language into other site languages. You choose whether T3AI translates only the page (title and page properties) or the page with all its content elements.

## Translate a page

1. Open the **Page** module and select the page in the default language.
2. At the top, click **Translate with T3AI**.
3. Select the **AI Provider**.
4. Under **Choose Language**, select a language or **All**.
5. Click **Translate Page** (page only) or **Translate Page & Content** (page and its content elements).

**Result:** The page translation is created. Translated content elements are hidden until you activate them, see [Activate Translated Content](/en/latest/ExtNsT3AI/Translation/ActivateTranslatedContent/Index).

<Note>
**Translate with T3AI** is shown only while the page has site languages without a translation. To translate again, use [Re-Translate Pages](/en/latest/ExtNsT3AI/Translation/ReTranslatePages/Index).
</Note>
