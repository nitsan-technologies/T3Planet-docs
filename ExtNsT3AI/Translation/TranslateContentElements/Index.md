## Translate a content element

1. Edit the content element in the default language.
2. In the form header, click **Translate with T3AI**.
3. Select the **AI Provider** and the target language, then click **Translate Record**.

**Result:** The translation of the element in the target language.

## Re-translate a translated element

Edit the translated element and choose a provider in the **Translate with T3AI** dropdown in the form header, for example **Deepl** or **ChatGPT**. T3AI replaces the text with a new translation of the original.

To translate a page with all its elements at once, use [One-Click Page Translations](/en/latest/ExtNsT3AI/Translation/OneClickPageTranslations/Index).
