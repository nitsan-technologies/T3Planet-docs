## What does T3AI do?

**T3AI** (`EXT:ns_t3ai`), shown in the backend as **AI Assistant**, adds AI tools for editors to the TYPO3 backend:

| Area | What you can do |
|---|---|
| [Pages](/en/latest/ExtNsT3AI/Pages/Index) | Create pages, blog posts, news, and whole page trees |
| [SEO](/en/latest/ExtNsT3AI/SEO/Index) | Write meta and Open Graph texts, analyse content, add schema markup, and optimize many pages with [Mass SEO](/en/latest/ExtNsT3AI/MassSEO/Index) |
| [Content](/en/latest/ExtNsT3AI/Content/Index) | Write and rewrite text in the rich text editor and in content elements |
| [Translation](/en/latest/ExtNsT3AI/Translation/Index) | Translate pages, content, news, and records, one by one or in bulk |
| [Media](/en/latest/ExtNsT3AI/Media/Index) | Generate AI images or import free stock images |
| [Prompts](/en/latest/ExtNsT3AI/Prompts/Index) | Adjust the instructions T3AI sends to the AI |
| [Ask AI agent](/en/latest/ExtNsT3AI/AskAiAgent/Index) | Run T3AI features from a chat in plain language |

## How it fits together

T3AI is a child extension of **AI Foundation** (`EXT:ns_t3af`). AI Foundation holds the AI providers, settings, prompts, permissions, and logs. T3AI adds the editor tools in **AI Universe > AI Assistant** and in the Page module, the rich text editor, and the record forms.
